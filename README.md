# Кухня-гостиная, кв. 569 — 3D

Интерактивная 3D-визуализация кухни-гостиной (Three.js r128, один самодостаточный HTML, все текстуры процедурные).

**Живая версия:** https://papalkov.github.io/569-flat-design/

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | сама сцена, открывается локально двойным кликом или по ссылке выше |
| `kitchen-living-569-context.md` | контекст проекта: размеры по чертежу, принятые решения, палитра, устройство сцены |
| `docs/plan-569.jpg` | чертёж застройщика, кв. 569 |

## Управление

Мышь / тач — вращение, колесо или щипок — зум. Клик по предмету показывает подпись.
Кнопки внизу: «Вечер», «Автовращение», «Сбросить вид».
