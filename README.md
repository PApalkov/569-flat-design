# Квартира 569 — планировка, 3D и электрика

Интерактивный рабочий документ по ремонту: вся квартира в 3D, 2D-план с размерами,
карта розеток «что есть / что добавить» и текстовое описание отделки.
Один самодостаточный HTML на Three.js, все текстуры процедурные, внешних картинок нет
(кроме фотографий объекта в `docs/`).

**Живая версия:** https://papalkov.github.io/569-flat-design/

## Вкладки

| Вкладка | Что внутри |
|---|---|
| **3D** | три режима: «Сверху» — вся квартира на полную высоту, ближние стены убираются; «Комната» — орбита вокруг кухни-гостиной; «Пройтись» — вид от первого лица, объектив 24 мм, WASD и касание пола |
| **План** | 2D-план: стены, мебель, размеры, розетки и вода. Нажатие на пол переносит в 3D в эту точку. Кнопки зума по комнатам |
| **Розетки** | таблица всех точек: существующие (снято с фото) и предлагаемые, с координатами, высотами и группами автоматов |
| **Гаммы** | четыре цветовые палитры комнат при неизменной кухне — стены, диван, текстиль, шкафы, плитка санузла; «Показать в 3D» перекрашивает сцену на месте |
| **Отделка** | палитра под выбранную кухню, решения по спальне, санузлу и прихожей с обоснованием, список «что проверить на месте» |

| Прихожая с тамбуром | — | 4,4 м² |

## Управление в 3D

Тяга — вращение, колесо или щипок — зум **к точке под курсором**, двойной тап по месту — приблизиться туда,
Shift + тяга или два пальца — сдвиг. В режиме «Пройтись» — WASD и касание пола.
Кнопка «Шторы» переключает ткань / рулонные / комби.

## Геометрия

Снята с чертежа обмером по пикселям: красный контур 708 × 577 px при масштабе
102,6 px/м → 6,90 × 5,63 м по внутренним граням. Начало координат — центр кухни-гостиной,
X вдоль комнаты (кухня на +X), Z поперёк (спальня на −Z), Y вверх, метры.

Высота потолка **2,70** (подтверждена владельцем) — во всех режимах стены полной высоты.

Сцена статична, поэтому кадр рисуется только после реального изменения — в покое видеокарта простаивает.
